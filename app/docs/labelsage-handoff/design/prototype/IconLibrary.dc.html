Icon library

{{count}} icons from one free library, Microsoft Fluent Emoji 3D (MIT), so every icon has the same 3D style and point of view. Where Fluent has no exact icon, the nearest one stands in (marked “nearest”, {{drawn}} icons): all tree nuts use the chestnut, sesame the bagel, mustard the hot dog, mussels the oyster. Every allergen, ingredient, diet and person in onboarding, preferences and the chat has one. The list lives in icons.json; the app ships them in the bundle, so they never wait for a server.
